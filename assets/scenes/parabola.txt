# Parabola — y = x² and its tangent line animation
# Demonstrates quadratic functions and derivatives

# The parabola curve: x goes from -2 to 2, y = x²
curve parabola  t/(2*pi)*4-2  (t/(2*pi)*4-2)^2/2  0   0.9 0.6 0.1

# Reference axes
line x_axis  -3 0 0   3 0 0   0.3 0.3 0.3
line y_axis  0 -1 0   0 4 0   0.3 0.3 0.3

# A point sliding along the parabola
quad point  yellow.png  0.12 0.12

# Vertex marker
line vertex_mark  -0.1 0 0   0.1 0 0   1 1 0

# Animate point along the parabola: starts at (-2, 2) → vertex (0,0) → (2, 2)
