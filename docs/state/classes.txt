QchuAnims - Class Reference
===========================

IEntity  (include/classes/entities/entity.h)
--------------------------------------------
Base interface for all scene objects.
Fields:   id (string), transform (Transform)
Methods:  draw(view, projection) [pure virtual]
          getPosition/setPosition, getRotation/setRotation, getScale/setScale

Transform  (same file)
  position, rotation (degrees), scale  — all glm::vec3
  getModelMatrix() → glm::mat4

Concrete entities
  Line   (x1,y1,z1) → (x2,y2,z2), color rgb       uses gizmoShader
  Quad   4 vertices + textureID                     uses textureShader
  Curve  parametric fn(t)→vec3, color rgb           uses gizmoShader
  Axises global XYZ reference lines                 uses gizmoShader

─────────────────────────────────────────────────────────────────────

Scene  (include/classes/scenes/scene.h)
---------------------------------------
Data container. No OpenGL, no file I/O.
Fields:   id (string)
          entities   map<string, IEntity*>
          animations vector<IAnimation*>
Methods:  addEntity(id, ptr), addAnimation(ptr)
          getEntities(), getAnimations()
          getEntity(id) → IEntity*  (returns nullptr if not found)
Owns its entities and animations (deletes in destructor).

─────────────────────────────────────────────────────────────────────

ScenesParser  (include/classes/creation/scenes_parser.h)
---------------------------------------------------------
Reads .txt scene files and builds Scene objects.
Constructor: ScenesParser(Renderer* r)
Methods:
  extractScenes(folder_path) → vector<unique_ptr<Scene>>
    iterates folder, calls parseFile for each .txt
  parseFile(file_path)       → unique_ptr<Scene>
    scene id = filename stem (e.g. "main_scene")
  parseLine / createEntity   (private)
    dispatches on first token: line | quad | curve

Expression evaluation (curves):
  Uses tinyexpr. ExprContext compiles x(t), y(t), z(t) at parse time.
  Lambda captures shared_ptr<ExprContext>, evaluates at draw time.

─────────────────────────────────────────────────────────────────────

ScenesManager  (include/classes/scenes/scenes_manager.h)
---------------------------------------------------------
Owns all scenes, manages the active one.
Constructor: ScenesManager(vector<unique_ptr<Scene>>)
Methods:
  getCurrentScene()        → Scene*
  setCurrentScene(id)      sets active scene by id string

─────────────────────────────────────────────────────────────────────

Engine  (include/classes/engine.h)
-----------------------------------
Top-level class. Entry point is main.cpp.
init(w, h, title)  → creates window, loads OpenGL, creates Renderer
run()              → builds scenes via parser, hands to manager, main loop
processInput()     → WASD + mouse → camera, ESC → close

─────────────────────────────────────────────────────────────────────

Renderer  (include/classes/render/renderer.h)
----------------------------------------------
Owns: gizmoShader, textureShader, camera, axises, texture cache
clear(r,g,b,a)                  glClear
drawScene(entities)             draws axises + all entities
getOrCreateTexture(filename)    loads from assets/textures/ if not cached
getGizmoShader() / getTextureShader()

Camera  (include/classes/render/camera.h)
  ProcessKeyboard(direction, deltaTime)
  ProcessMouseMovement(xoffset, yoffset)
  GetViewMatrix() → glm::mat4

Shader  (include/classes/render/shader.h)
  Loads and compiles vertex + fragment GLSL files.
  setMat4 / setInt helpers.

─────────────────────────────────────────────────────────────────────

EasingType  (include/classes/animations/easing_type.h)
  enum class EasingType { LINEAR, EASE_IN, EASE_OUT, EASE_IN_OUT }

Keyframe  (include/classes/animations/keyframe.h)
  Fields: time (float), value (glm::vec3)

TransformProp / InterpolationMode / Track  (include/classes/animations/track.h)
  enum class TransformProp     { POSITION, ROTATION, SCALE }
  enum class InterpolationMode { LINEAR, SMOOTH }
  struct Track: entity_id, property, easing, interpolation, vector<Keyframe>

IAnimation / Animation  (include/classes/animations/animation.h)
  IAnimation: base interface with virtual destructor
  Animation:  startTime, duration, vector<Track>

applyEasing  (include/classes/animations/easing.h)
  inline float applyEasing(float alpha, EasingType) — 4 easing types

evaluate  (include/classes/animations/evaluate.h)
  inline glm::vec3 evaluate(const Track&, float localT)
  Dispatches to glm::mix (LINEAR) or Catmull-Rom spline (SMOOTH)

Transformation  (include/classes/animations/transformation.h)
  Legacy stub — unused, kept for reference.

Animator  (include/classes/animations/animator.h / src/classes/animations/animator.cpp)
  Fields:  t (float) — global playback time
  Methods: update(float deltaTime, Scene*) — advances t, evaluates all tracks, writes transforms
           reset() — resets t to 0
  Connected to main loop in Engine::run() before drawScene().
