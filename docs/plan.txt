"scene_i.txt" Format:

    # CREATION
        line id x1 y1 z1 x2 y2 z2 r g b
        
        # Multiple creation formats
        quad id texture x1 y1 z1 x2 y2 z2 x3 y3 z3 x4 y4 z4
        quad id texture w h
        quad id texture
        
        curve id x(t) y(t) z(t) r g b

    # ANIMATION
        animate id transform_type  arg x y z
            # transform_type: position/rotation/scale
            # formula(t): example --> { sin(t) where 0 <= t <= 1 }
        wait ammount



## Steps:
    Curve:  
    - Is an Entity, has a transform, a draw and a shader ref.
    - As a curve it has a parametric function, is a function with variable t and returns a vec3
    - At creation we create the vertices of the functio  by adding small steps of t
